# fume5
a fume extractor for $5

## why fume5?

fume extractors are really expensive. at home depot, the first option is $315 and the cheapest one is $58. most teenagers cannot afford that, so they just solder without any protection. i wanted to build something cheap and reliable that people can actually afford. that's why i created fume5.
